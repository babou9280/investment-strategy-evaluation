Guide de la critique Gate 1

Ce package est un prototype de compréhension. Il ne constitue ni un produit publié, ni une validation commerciale, juridique ou utilisateur.

Ouvrir

  1. Ouvrir directement Breaktest_Cost_Gate_Gate_1.html lorsqu’il est fourni séparément.
  2. Dans le ZIP d’audit, ouvrir index.html ; ce point d’entrée est lui aussi autonome.
  3. Choisir une saisie vide ou charger volontairement la démonstration synthétique.
  4. Si l’avertissement « moteur non actif » apparaît, changer d’application de lecture : les champs ne doivent jamais être effacés silencieusement.

Vérifier

  • La provenance reste visible.
  • Tout changement masque l'ancien résultat.
  • Les constats et couches non évaluées restent accessibles.
  • Le manifeste réconcilie les fichiers et empreintes.

Limites

  • Aucune donnée de marché ou de compte réelle.
  • Aucune liquidité ou probabilité d'exécution.
  • Aucune recommandation ni transmission d'ordre.
  • Safari/iPad non revendiqué sans essai réel distinct.
